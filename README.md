# Dom-D — Строительство деревянных домов

Учебный проект адаптивного лендинга компании по строительству деревянных домов. Это мой четвёртый проект, на котором я закрепляю модульную SCSS-архитектуру и создаю наиболее масштабный сайт из всех предыдущих работ.

## Цель проекта
Построить полноценный лендинг с множеством секций, сложной адаптивной вёрсткой под четыре брейкпоинта и модульной организацией SCSS-кода по блокам.

## Технологии
* **HTML5**: семантическая разметка, `<article>`, `<section>`, `<header>`, `<footer>`, `<nav>`, формы, инлайн SVG-иконки.
* **SCSS**: модульная структура с папкой `blocks/` (17 файлов по секциям), CSS-переменные через `:root`, медиамиксины `fluid-font`, `fluid-width`, `fluid-height`, `reset-button`, `reset-link`.
* **CSS3**: Flexbox, CSS Grid (`repeat()`, `grid-template-columns/rows`), `clamp()`, `calc()`, `backdrop-filter: blur()`, `background-image`, `box-shadow`, `text-shadow`, градиенты, `:hover`, `::before`/`::after`.
* **Normalize.css**: пакет `@a1rth/css-normalize`.

## Чему я научился
* Организовывать SCSS по блокам — каждый компонент в отдельном файле.
* Работать с четырьмя брейкпоинтами: desktop (1920px+), laptop (1366px), tablet (768px), mobile (375px).
* Использовать `clamp()` для адаптивных размеров без медиазапросов.
* Создавать адаптивные grid-раскладки, перестраивающиеся на разных экранах.
* Работать с `backdrop-filter`, градиентами и полупрозрачными фоном.
* Стилизовать формы и текстовые поля с кастомными тенями.

## Потеря исходных SCSS-файлов
В ходе работы над проектом были случайно потеряны файлы: `styles.scss` (главный файл с `@import`), а также `_variables.scss`, `_utils.scss`, `_normalize.scss`, `_mixins.scss`, `_media.scss`, `_globals.scss`, `_fonts.scss`. Эти файлы по структуре аналогичны тем, что используются в проекте «traveling-to-russia». Скомпилированный `styles.css` сохранился до момента потери, поэтому проект полностью рабочий. Исходные стили блоков из папки `blocks/` остались без изменений.

## Текущее состояние
* **Адаптивность**: страница адаптирована под desktop, laptop, tablet и mobile.
* **JavaScript**: не используется — интерактивных элементов (слайдеры, бургер-меню) нет, заготовки присутствуют в HTML.
* **Код**: самый масштабный проект на данный момент по количеству секций и объёму стилей.
